# tools — утилиты для разработчика: иконки и диагностика роутера через SAM

Ничего отсюда не попадает в сборки. Всё запускается вручную.

## Что здесь

| Файл | Что делает | Как запускать |
|---|---|---|
| `gen-icons.sh` | Растеризует все иконки приложения (Tauri и Android) из `core/icons/icon.svg`. PNG хранятся в репозитории: ни бандлер Tauri, ни ресурсы Android не умеют растеризовать SVG сами. | `tools/gen-icons.sh` после правки SVG, затем закоммитить PNG |
| `sam-eepsite.py` | Открывает настоящие eepsite через роутер на SAM 7656. Адреса берёт из официального `hosts.txt`, минуя NAMING LOOKUP. Проверяет туннели, поиск LeaseSet и стриминг, то есть отвечает на вопрос «роутер работает или сломан наш код». | `python3 tools/sam-eepsite.py` при запущенном i2pd с SAM на 127.0.0.1:7656 |
| `sam-probe.py` | Две SAM-сессии на одном роутере (релей и бот). Это воспроизведение сбоя CI времён go-i2p, когда вторая сессия не получала ответа. | `python3 tools/sam-probe.py` при запущенном роутере |
| `ovpn_to_singbox.py`, `build_balanced_singbox.py` | Конвертеры конфигов OpenVPN в sing-box. **К gipny не относятся**, лежат здесь исторически. | — |

## Куда вносить правки

| Задача | Файл |
|---|---|
| Поменять иконку приложения | `core/icons/icon.svg`, затем `tools/gen-icons.sh` |
| Добавить размер или платформу иконок | `tools/gen-icons.sh` |
| Проверить роутер без приложения | `tools/sam-eepsite.py` |
| Разобраться с несколькими SAM-сессиями на одном роутере | `tools/sam-probe.py` |

## Грабли

- Скрипты SAM ждут роутер на `127.0.0.1:7656`. Приложение на десктопе выбирает свободный порт само: смотрите его в логе приложения, либо поднимите i2pd с `--sam.port=7656` (так делает `tests/e2e-harness/start-router.sh`).
- При работающем `sam-eepsite.py` проблема доставки почти наверняка в нашем коде, а не в сети.

## Как проверить

Отдельных тестов нет: инструменты сами являются проверкой. После `gen-icons.sh` проверьте `git status`, что PNG обновились, и что `build.yml` (`android APK`, `rust workspace`) проходит.
