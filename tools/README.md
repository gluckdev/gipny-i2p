# tools — утилиты для разработчика

Ничего отсюда не попадает в сборки. Всё запускается вручную.

## Что здесь

| Файл | Что делает | Как запускать |
|---|---|---|
| `gen-icons.sh` | Растеризует все иконки приложения (Tauri и Android) из `core/icons/icon.svg`. PNG хранятся в репозитории: ни бандлер Tauri, ни ресурсы Android не умеют растеризовать SVG сами. | `tools/gen-icons.sh` после правки SVG, затем закоммитить PNG |
| `ovpn_to_singbox.py`, `build_balanced_singbox.py` | Конвертеры конфигов OpenVPN в sing-box. **К gipny не относятся**, лежат здесь исторически. | — |

Диагностика роутера через SAM (`sam-eepsite.py`, `sam-probe.py`) удалена вместе с SAM: роутер вкомпилирован в каждый бинарь (`i2p-embed`). Проверить его без приложения можно live-тестом `i2p-embed` (`i2p-embed.yml`: две destination в одном роутере, эхо по живой i2p).

## Куда вносить правки

| Задача | Файл |
|---|---|
| Поменять иконку приложения | `core/icons/icon.svg`, затем `tools/gen-icons.sh` |
| Добавить размер или платформу иконок | `tools/gen-icons.sh` |

## Как проверить

Отдельных тестов нет. После `gen-icons.sh` проверьте `git status`, что PNG обновились, и что `build.yml` (`android APK`, `rust workspace`) проходит.
