# Условия первого beta-релиза

Обновлено: 2026-11-16. Это действующий план, **не список готовых функций**.
Ветка `release/0.5.0-beta.1`; alpha2 не публикуется. Метаданные пакетов обновлены до beta.1 в `bb68aa7`. [Сверка условий 18 ноября](../audits/2026-11-18-plan-review.md).

## Названия и совместимость

Сеть приложения — I2P, её схема объединения сообщений называется garlic
routing. В собственном коде используются `I2pNode`, `i2p_address`,
`relay_address`, `my_i2p_address`; аргументы Tauri сохраняют его camelCase
convention (`i2pAddress`). `destination` означает полную I2P Destination.
Не вводим `.garlic` адреса и не называем I2P новой версией другой сети.

По прямому решению владельца старые профили, JSON/SQL схемы и API не требуют
совместимости, aliases или миграций. Это позволяет изменить поля сразу во
всех слоях. Существующие данные пользователя не стираются фоновым заданием.
Транзакции, ratchet, replay-защита и целостность новых данных остаются обязательны.
Upstream/generated-код и названия внешних проектов в первоисточниках не меняются.

## Выпуск блокируют

| Область | Что должно быть готово | Доказательство |
|---|---|---|
| Naming | Одинаковые поля Rust, WASM, UI, IPC, SQL, fixtures и docs | Компиляция всех клиентов, codec/IPC тесты, поиск оставшихся собственных названий |
| Установка | Широкая проверенная матрица, корректный выбор OS/ABI, Android 16 KiB | [Платформы](../platform-support.md); каждый shipped target собран и запущен, без фиктивных universal claims |
| Web | Собственный router, доступная публичная конфигурация/bridge, понятные capability errors | WSS/WebRTC, браузерная матрица, Honor Cromite и realme Chrome; TURN отдельно |
| Сеть | Адаптация по полезной скорости и ресурсам, а не по числу CPU | Сравнимый повтор, ограничение памяти/потоков, hysteresis, замеры latency под загрузкой |
| Файлы | Сохранение проверенных принятых частей, корректные ACK и повтор после сбоев | Crash/storage/network faults, sparse bitmap, повреждения, ratchet/replay tests |
| Перенос | Одна активная личность, пароль с обеих сторон, только I2P, source ОК/Отмена после полного приёма | [Протокол и модель отказов](../profile-transfer.md), все native/browser сочетания, независимый review |
| UI | Полная карточка добавляется автоматически, QR возле имени, лёгкие эффекты, цифры/Shift на клавиатуре | Unit + реальный renderer: узкие экраны, темы, focus, reduced motion, camera cancellation |
| Документация | Текущее поведение, ограничения и все настройки описаны RU/EN | Проверка ссылок/команд; отменённые планы не выглядят инструкциями |
| Release | Все ветки объединены, один проверенный source SHA, provenance и подписи | Локальные gates, GitHub матрица, проверка содержимого/установки артефактов |

## Текущее доказательство

На `589ad57` прошли native delivery, browser WSS/WebRTC, сборки, security,
CodeQL и installer checks. Это baseline до beta изменений. Браузерные fixture
тесты не являются проверкой физических телефонов или TURN. Первое измерение
1…8 lanes полностью доставило файлы, но не выдержало все интерактивные deadlines.
Повтор 6,4,6,4 прерван ошибкой harness; она исправлена в `f73fd42`.
Результаты — [производительность](../performance-anonymity.md).

UI улучшения сохранены в `b9f3dc0`; новые изменения имён и клавиатуры требуют
повторной проверки. Android alignment исправлен в `97d15b4`, 15 структурных
тестов прошли; новый APK и запуск в 16 KiB среде ещё не подтверждены.
Profile transfer пока проектируется; существующий backup не удовлетворяет ему.

## English

This plan supersedes alpha2 publication. Beta requires a complete tested profile
move over I2P, wider verified platform/browser coverage, measured network
adaptation, durable file recovery, UI improvements and current documentation.
Old-data compatibility, aliases and migrations are explicitly out of scope;
existing user files must not be silently deleted. Preserve the integrity of
new data and cryptographic state. Earlier CI is baseline evidence, never a
substitute for checks on the final integrated beta source and shipped artifacts.
