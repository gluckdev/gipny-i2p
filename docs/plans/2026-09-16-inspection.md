### 3B. Отгружено в v0.4.0

1. **`gipny-agent_0.4.0_linux-*.tar.gz` не запускается на чистом хосте.** В архиве только бинарь + README.txt (джоба `agent` в `release.yml` — `needs: version`, артефакт роутера не берётся; у `relay` — `install router/i2pd`). `router.rs:339-361` ищет `i2pd` рядом с exe, в `resources`, `../lib`, `../Resources`, потом `PATH` (или `GIPNY_I2P_BIN`). README: «Автоматически поднимает I2P-стек» — неправда без системного i2pd, `GIPNY_I2P_BIN` или `--sam`.
2. **Встроенный релей (`eb339bd`) — ловушка при перезапуске.** `EphemeralRelay::start` (`relay_server.rs:422`) генерирует **новый destination при каждом старте**, ключ только в памяти. `start_hosted_relay` (`core.rs:281`) записывает его в `SETTING_RELAY_ONION` как **свой** релей; `Core::start` релей не поднимает (`hosted_relay: None`); `stop_hosted_relay` прежний адрес **не восстанавливает**. Плюс «relay discovery» рассылает этот адрес всем контактам в каждом сообщении → их БД теперь указывают на релей, который умрёт при закрытии приложения. Итог: нажал «Запустить встроенный релей» → закрыл приложение → **клиент слушает мёртвый релей, контакты кладут туда же**, выход только руками через поле релея. Дополнительно: Tauri-команда ждёт постройку туннелей (1–2 мин) — кнопка крутится, хотя док-комментарий `EphemeralRelay` прямо запрещает так делать. В release notes 0.4.0 это заявлено как фича.
3. **Relay discovery** (`eb339bd`): каждое исходящее сообщение (включая typing) теперь несёт `relay_address` (~520 Б) и всегда кодируется полным `WirePayload`; релей контакта молча переписывается при любом входящем. Криптографически безопасно (внутри ratchet), но недокументировано и без сигнала в UI. Не ломает — но нужно осознанно принять или откатить.
4. Агент выполняет команды параллельно (см. §2) — на проде это перемешанный вывод.
5. Релиз **не проверен по живому i2p** — `e2e-i2pd` не запускался после `4c5f6a1`.
6. `SECURITY.md` — незаполненный шаблон GitHub («5.1.x supported»).

### 3C. Дизайн-ловушка (сделано по плану, но сказать честно)

`persist_incoming` ставит `console_pending_` на **любую** COMMAND от **любого** контакта (`core.rs:1620`). Включение режима агента для X немедленно выполняет всё, что X когда-либо присылал. План одобрил «отложенные — после включения», но фактическая область — «любой, кто позже станет мастером». Маркеры для не-мастеров живут до удаления сообщения.

### Дорожка B — ветка `feat/attachment-privacy`: доделать security-фичи

#### B1. Приватность вложений (`core/src/sanitizer.rs`, переписать)

**Дизайн:**
- Настройка «приватность вложений» (по умолчанию **включена**), хранится в `settings` ядра (`SETTING_ATTACHMENT_PRIVACY`), Tauri `get/set_attachment_privacy`, тумблер в `settings.ts` рядом с appearance. Пояснение: «из фото и PDF удаляются EXIF/XMP/IPTC и авторские поля; имена фото с камеры заменяются на нейтральные».
- Применяется **только** в `send_message_paths` (`lib.rs:857`) и групповом пути (`:1158`). **Не** применяется в `send_console_command` (`:726`) — файл для агента должен прийти байт-в-байт и с тем же именем: `read_one_attachment(p, sanitize: bool)`.
- **Имена**: переименовывать только то, что похоже на автоимя камеры/скриншота (`IMG_…`, `DSC…`, `PXL_…`, `Screenshot…`, `Снимок экрана…`, `<ts>-clipboard.png`) → `photo_<6 hex sha256>.ext`. Осмысленные имена (`Отчёт_Q3.docx`) не трогать.
- **JPEG**: список на удаление (denylist, всё прочее сохраняется — в частности `APP14` Adobe, без него CMYK-JPEG меняет цвет): APP1 (EXIF + XMP), APP13 (IPTC/Photoshop), COM, APP2 кроме `ICC_PROFILE\0` (т.е. MPF с вложенными картинками iPhone — убрать, ICC — оставить). **Orientation сохранить**: прочитать тег 0x0112 из исходного EXIF и записать минимальный APP1 (TIFF-заголовок + один IFD-entry, ~40 байт). Пиксели не перекодировать. **Хвост после EOI обрезать**: Google/Samsung «Motion Photo» кладут MP4 *после* `FFD9` (XMP на него ссылается, но без XMP видео всё равно остаётся) — текущий парсер копирует всё после SOS как есть; новый должен пройти энтропийный сегмент до настоящего `FFD9` (пропуская `FF00` и RSTn) и отрезать остальное.
- **PNG**: убрать `eXIf`, `tEXt`, `zTXt`, `iTXt`, `tIME`; `pHYs`, `iCCP`, `sRGB`, `gAMA` оставить.
- **WebP**: RIFF-обход, убрать чанки `EXIF`, `XMP ` **и сбросить биты EXIF/XMP во флагах `VP8X`** — иначе часть декодеров отвергает файл; пересчитать размер RIFF.
- **PDF**: текущий побайтовый поиск выбросить. Добавить `lopdf` (pure Rust): удалить объект `/Info` из trailer и **все** `/Metadata` (XMP) — в каталоге, в каждой странице и в form XObject'ах (пройти все словари), пересохранить. Если `lopdf` не смог разобрать (шифрованный, битый) — **отказ отправки** с понятной ошибкой в UI («не удалось очистить метаданные PDF — выключите приватность вложений или отправьте другой файл»), а не тихая отправка как есть.
- **HEIC/HEIF/AVIF/TIFF и MP4/MOV** тоже несут GPS и модель устройства (iPhone снимает HEIC по умолчанию). Молча пропускать нельзя — тумблер обещает «фото очищены». Поведение: **fail-closed** для расширений картинок/видео вне обработанного набора («формат не поддерживается очисткой — выключите приватность вложений или конвертируйте в JPEG/PNG»).
