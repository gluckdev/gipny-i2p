## Что нового в 0.4.13

**Письма тем, кого нет в сети, больше не пропадают вместе с отправителем.**

- **Письмо считается оставленным в сети, только когда его взял кто-то другой.** Приложение на компьютере и агент сами хранят письма для других, и раньше собственная копия засчитывалась как «письмо в сети». Если в этот момент никто больше письмо не принял, оно лежало только у отправителя — и пропадало, когда тот закрывал приложение. Теперь своя копия по-прежнему хранится, но письмо считается ушедшим, только когда его держит хотя бы один другой узел; до тех пор оно остаётся в очереди и отправляется снова.

- **Единственный известный узел сети больше не выпадает после одной неудачи.** Узел, который не ответил, временно не участвует в поиске, чтобы не тормозить каждое письмо. Но если других узлов нет, приложение теперь всё равно пробует его, а не остаётся вовсе без сети до следующего обслуживания.

- **Подключение к собственному релею не может зависнуть навсегда.** Если сеть i2p оставляла такую попытку без ответа, приложение (или агент) так и не забирало свою почту до перезапуска. Теперь на попытку отводится полторы минуты, потом следующая.

### Важно знать

- **Постоянного узла сети в сборке пока нет.** Если перезапустились оба собеседника, найти друг друга им по-прежнему может быть не через что.
- **Установка APK на Android по-прежнему ручная.** Приложение сообщит о новой версии и даст скачать файл (Настройки → Android-приложение).
- Сборки для Windows и macOS не подписаны платными сертификатами — как их открыть, написано в разделе «Установка».
