## Что нового в 0.4.7

**Приложение на Android перестало падать.** Это весь релиз: одна ошибка, которая убивала его по несколько раз в час, и уборка вокруг сборки. Новых возможностей здесь нет — и не должно быть.

- **Падения на телефоне прекращены.** Приложение умирало прямо посреди работы и почти всегда при сворачивании, поэтому казалось, что его выносит система ради памяти. Это оказалось неправдой: на телефоне было свободно три гигабайта. Убивал его собственный код — проверка обновлений. Библиотека, которой мы поручили проверять сертификаты, на Android обращается к системе Android, и, не получив нужного ей доступа, обрывала не запрос, а **весь процесс целиком**. Проверка идёт по таймеру, отсюда и «падает, когда я просто им пользуюсь».
- **Обновления теперь нельзя подменить чужим сертификатом.** Попутно выяснилось кое-что серьёзнее падений. Приложение скачивает по этому же соединению установочный файл новой версии, а доверяло при этом списку удостоверяющих центров **самого устройства**. Корневой сертификат, поставленный системным администратором на рабочем телефоне, добавленный вами по невнимательности или установленный вредоносной программой, годился, чтобы выдать себя за GitHub и подсунуть своё обновление. Теперь приложение доверяет только своему встроенному списку и ничему больше.

### Для тех, кто следит за сборкой

- **Сборка перестала выбрасывать то, что уже собрано.** Релиз каждый раз начинал с нуля, и дело было не в настройках кеша: GitHub отдаёт сохранённое только запуску с той же ветки, а релиз идёт по тегу — всё, что он складывал, не мог прочитать уже никто. Порядок выпуска теперь начинается с прогона по основной ветке, и он записан там, где его найдут.
- **Сборка молчит.** Устранены все предупреждения, которые печатали наши собственные файлы и наши шаги, включая восемьсот строк от сборщика под Windows, за которыми потерялось бы любое настоящее. Осталось только чужое — из готовых компонентов, которые мы не пишем.
- **Мусор убирается сам.** Промежуточные файлы сборки живут пять дней вместо девяноста, а еженедельная уборка сносит остальное. Их скопилось почти тридцать гигабайт.

### Важно знать

- **Обновление обязательное.** На Android 0.4.6 падает; ставить его дальше нет смысла.
- **Приложение 0.4.6 обновится до 0.4.7 само** (Linux AppImage и `.deb`, Windows, агент) — новая версия заработает после перезапуска, приложение предложит его сразу.
- **На Android обновление ставится вручную:** системный установщик — не наше дело. Приложение сообщит о новой версии и даст скачать файл.
- Сборки для Windows и macOS не подписаны платными сертификатами — как их открыть, написано в разделе «Установка».
