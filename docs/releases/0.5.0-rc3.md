### Надёжность доставки

- **Входящее письмо больше не теряется при сбое.** Расшифровка расходует ключ
  сообщения, поэтому теперь состояние ratchet, расход одноразового ключа и само
  письмо сохраняются одной синхронной транзакцией («надёжный входящий ящик»).
  Релей получает подтверждение только после неё; ошибка диска или базы не
  подтверждается, а письмо дообрабатывается после перезапуска.
- **Повреждённое или поддельное начало сессии ничего не ломает.** Сначала
  проверяется подлинность, и только потом заменяется сессия, расходуется ключ и
  создаётся запрос контакта.
- Неверная длина ключа в сети больше не завершает приложение.
- Состав группы может менять только её участник; ключи участников закреплены.
- Повторно запущенное приложение или агент не откроет тот же профиль второй раз.
- Агент перепроверяет полномочия хозяина прямо перед запуском команды.
- Встроенный релей ограничивает число одновременных соединений и время на вход.

### Новое

- **Уведомления о действиях собеседника.** Если собеседник скопировал текст
  вашего сообщения, сохранил ваше вложение или нажал сочетание клавиш снимка
  экрана, под сообщением появится отметка — только у вас, автора. Передаётся
  лишь факт и время, без содержимого; удаление сообщения или истории удаляет и
  отметку. Сочетание клавиш не доказывает, что снимок сделан.
- **UPnP с переключателем и без следов.** Порт на домашнем роутере открывается
  автоматически (можно выключить в настройках роутера i2p). Описание правила не
  содержит имени приложения, метка своя для каждого шлюза, внешний IP
  публикуется только после подтверждённого проброса, а фокус окна больше не
  пересоздаёт правила. Подробности: [UPnP](../upnp.md).

### Веб-клиент

- Большие файлы: повтор потерянной части шифруется заново (старый способ ломал
  сессию с нативным клиентом), история повторов больше не переполняется,
  медленный контакт не останавливает передачи остальным, непринятым контактам
  ничего не отправляется автоматически. Одно зависшее соединение больше не
  задерживает всю очередь отправки: подтверждения и следующие части уходят,
  пока оно ждёт своего таймаута, а молчащий минуту поток закрывается, и
  письмо уходит повтором по новому вместо ожидания в несколько минут.
  Зависшее открытие файла в хранилище браузера больше не останавливает
  передачу: часть отправляется повторно, файл открывается один раз на серию
  частей.
- **Тёплый старт браузера:** клиент сохраняет то, что узнал о сети I2P, и при
  следующем запуске стартует с этого, даже если опубликованный снапшот
  недоступен (записи старше 36 часов по-прежнему отвергаются).
- Мост WSS/WebRTC: открываются только порты, похожие на I2P (служебные порты
  заблокированы), keepalive для прокси/CDN, TCP к узлу — после открытия канала,
  исправлены квоты окна и Worker.

### Интерфейс

- Отметки об удалении группируются по тому, кто удалил («вами» / «собеседником»),
  короче и понятнее; «ОК» работает и для больших очищенных чатов.
- Исправлены: зависание чата при удалении сообщения во время загрузки файлов;
  потеря черновика правки при смене языка и при прокрутке к старым удалениям;
  «Файл получен» на собственных файлах; вечная плашка «собеседник не сообщил о
  сохранении истории»; текст про автообновление на Android и macOS.
- При сбое этапа загрузки показывается причина; сбои релея и сети продолжаются
  в фоне без кнопки «назад».
- Поддержка Yggdrasil удалена: приложение работает только через I2P.

### English

Prerelease with the developer log on native clients, like rc1/rc2. Incoming
letters are now committed atomically with the ratchet state and one-time-prekey
use before the relay is acknowledged, and storage failures are retried instead
of acknowledged. X3DH inits are authenticated before any state changes. Group
changes require an existing member; malformed keys no longer crash; profiles
cannot be opened twice; agent permission is rechecked before running commands;
the embedded relay bounds connections. New: authors see when the contact copied
their text, saved their attachment or pressed a screenshot shortcut (no content
travels, deletion removes it); UPnP is switchable, neutral and per-gateway.
The browser keeps its live netDb between starts and can start from it without
the published snapshot. Browser large-file transfer, the WSS/WebRTC bridge and
several UI defects are fixed. Yggdrasil support is removed: I2P only.
