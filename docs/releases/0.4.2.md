## Что нового в 0.4.2

**Релей теперь встроен в каждое приложение и в `gipny-agent`, и включается сам.** Ничего настраивать не нужно: установили, создали профиль, через 1–2 минуты можно переписываться.

- **Встроенный релей — по умолчанию.** При запуске приложение поднимает релей внутри себя и получает почту через него. В 0.4.1 новый профиль встречал сообщение «релей не настроен» и пустое поле в настройках; этого больше нет. Пока релей строит туннели, вверху видно «встроенный релей запускается», затем приложение само сообщает новый адрес всем, с кем уже есть переписка.
- **Адрес релея новый при каждом запуске — так задумано.** Он живёт только в памяти и нигде не сохраняется: постоянного адреса, по появлениям которого в сети можно было бы вычислить часы вашей активности, нет. Это отменяет обещание из заметок 0.4.1 «релей, который переживает перезапуск, будет отдельно» — релей, переживающий перезапуск, это *внешний* релей, и он по-прежнему поддерживается.
- **Релей личный.** Он хранит письма и prekey-пакет только своего владельца и отказывает всем остальным — чужую почту ваше приложение не держит.
- **Настройки → relay:** переключатель «встроенный / внешний». У кого в профиле уже был указан релей, тот остаётся на нём — обновление никого не переносит.
- **«Моя карточка»** не показывает и не даёт скопировать карточку, пока у релея нет адреса: по карточке без релея вам не смогли бы написать. Карточка появляется сама, как только релей готов.
- **Пометка «контакт недоступен»** в чате, если письма ждут отправки, а релей контакта молчит дольше 10 минут, — с подсказкой, что делать.
- **Агент тоже получил встроенный релей.** `gipny-agent` поднимает личный релей для себя при каждом запуске, точно как приложение, — выделенный релей ему больше не нужен. `--relay` теперь необязательный внешний адрес (запоминается, как `--master`), для тех, кому нужен почтовый ящик агента, принимающий команды, пока агент выключен. Направленный на чужой личный релей, агент завершается с понятным объяснением вместо молчаливого ожидания команд, которые никогда не придут.
- **Ошибки релея больше не глотаются молча** — они видны в журнале приложения, бота и агента.

### Важно знать

- **Встроенный релей доставляет, пока открыты оба приложения.** Почтового ящика «на потом» у него нет: письмо контакту, которого нет в сети, ждёт в очереди у отправителя и уходит, когда контакт появится.
- **Если вы оба перезапустили приложения, ни разу не оказавшись в сети одновременно,** адреса друг друга устарели у обоих. Обменяйтесь свежими карточками: *моя карточка → Copy card*, собеседник добавляет контакт заново — история и ключи сохраняются, обновляется только адрес.
- **Нужна доставка, пока приложение закрыто** (разные часовые пояса; телефон, который усыпляет приложение) — *Настройки → relay → «внешний»* и адрес выделенного релея из архива `gipny-relay` ниже.
- **`gipny-agent` тоже доставляет, пока агент запущен.** Как и приложению, ему нужна доставка «на потом» — только если это важно для ваших сценариев: тогда поднимите `gipny-relay` и запустите агента с `--relay <адрес>`.
- **Нажимали в 0.4.0 «Запустить встроенный релей»** и в поле релея остался тот адрес? Переключите *Настройки → relay* на «встроенный» — автоматически 0.4.2 такой профиль не трогает, потому что не может отличить мёртвый адрес от рабочего.
- **Режим агента:** включая его для контакта, вы запускаете и все команды, которые этот контакт присылал раньше, пока режим был выключен.
- Сборки для Windows и macOS не подписаны платными сертификатами — как их открыть, написано в разделе «Установка».
