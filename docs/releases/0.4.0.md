## Что нового в 0.4.0

Первая версия на роутере **i2pd**. Все версии до неё (0.3.x) работали на go-i2p и сообщения не доставляли — обновитесь.

- **Сообщения доставляются.** i2pd встроен во все сборки, на Android — прямо в приложение. Доставку по живой сети i2p проверяет автоматический тест при каждом изменении роутера.
- **Свой релей у каждого.** В карточке контакта теперь есть адрес его релея, и сообщение уходит туда, откуда его заберёт получатель. Можно пользоваться разными релеями, без одной общей точки отказа.
- **Новые платформы:** macOS (Apple Silicon и Intel), Linux ARM64, 32-битный Android и готовые архивы релея для серверов.
- **Новый вид:** светлая тема по умолчанию, тёмная и «как в системе» — в настройках; новый логотип и иконки.
- **Настройки сети:** доля транзитного трафика (экономно / обычно / щедро) и Yggdrasil (выключен / автоматически / всегда). «Автоматически» включает Yggdrasil, только если i2p не смог подняться.
- **Безопасность:** в релее закрыта дыра, позволявшая стирать чужие недоставленные сообщения.

### Важно знать

- **Для переписки нужен релей.** Общего релея в приложении пока нет. Вставьте адрес релея в *Настройках* или поднимите свой из архива `gipny-relay` ниже. Без релея приложение запустится, но отправлять будет некуда — об этом предупредит баннер.
- Сборки для Windows и macOS не подписаны платными сертификатами — как их открыть, написано в разделе «Установка».
